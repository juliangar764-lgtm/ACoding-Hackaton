Koda - Aprende POO con Swift 🚀

Koda es una aplicación educativa nativa para iOS diseñada para enseñar los fundamentos de la Programación Orientada a Objetos (POO) de una manera interactiva, clara y moderna.

A través de lecciones dinámicas, la app guía al usuario paso a paso combinando teoría, ejemplos prácticos y asistencia inteligente.

✨ Características Principales

📚 Lecciones y Ejemplos Prácticos: Explicaciones breves y directas sobre los pilares de la POO (Clases, Objetos, Encapsulamiento, Herencia y Polimorfismo), acompañadas de metáforas visuales para facilitar el aprendizaje.

🤖 Tutor Virtual Inteligente: Un chat interactivo integrado donde puedes hacerle preguntas al tutor virtual sobre cualquier tema de programación o pedirle que aclare tus dudas en tiempo real.

🗣️ Soporte de Voz: Accesibilidad mejorada gracias a la integración de servicios de reconocimiento y síntesis de voz, permitiendo interactuar con el tutor de forma natural.

📊 Seguimiento de Progreso: Sistema de perfiles que guarda tu avance a medida que completas los diferentes temas y módulos.

🛠️ Tecnologías y Arquitectura

Este proyecto está construido con un enfoque 100% nativo para el ecosistema de Apple, utilizando las mejores prácticas de desarrollo móvil:

Lenguaje: Swift

Interfaz de Usuario: SwiftUI

Arquitectura: MVVM (Model-View-ViewModel) para una separación limpia entre la lógica de negocio y las vistas.

📱 Estructura del Proyecto

Features/: Contiene los módulos principales de la app como el Chat del tutor, las lecciones, la pantalla de inicio y el perfil del estudiante.

Models/: Definición de las estructuras de datos, progreso del usuario y el contexto del tutor.

App/: Configuración inicial y servicios base de la aplicación.
